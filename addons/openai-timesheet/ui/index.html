画像・PDFから読み込み

画像を準備

送信するのは、原画欄・動画欄から切り出して下に表示する画像だけです。元ファイル・PDF・ファイル名は送信しません。自動検出とPDFの画像化はこの端末内で行います。

1. 読み込みと範囲指定

PNG / JPEG / WebP / TGA / PDF · ファイルは一度に8個まで

タイトルやカット名を含めず、欄名・列名とコマの罫線を含む範囲を指定してください。自動検出後も範囲を削除し、ドラッグで指定し直せます。開始コマとコマ数は用紙に合わせて確認してください。

2. 送信画像を確認

0範囲

ここに表示された画像だけをOpenAIに送信します。不要な範囲は削除してください。API利用料は設定したキーのアカウントに発生します。

原画欄・動画欄を自動検出するか、手動で追加してください。

キーは保存しません。画像入力とStructured Outputsに対応するモデルを指定してください。

3. 認識結果を確認・修正

原画欄と動画欄はそれぞれ別タブに取り込みます。黄色の行は値・コマ位置を確認して「確認済み」を選んでください。空欄のまま確認すると、未入力のセルとして取り込みます。
